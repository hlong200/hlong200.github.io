# hlong200.github.io

Personal portfolio site for Hunter Long, served with GitHub Pages at [hlong200.github.io](https://hlong200.github.io).

## About me

I'm a computer science student at Missouri State University, finishing in 2027. I'm at my best seeing how the pieces of a system fit together and catching the small faults that can quietly break it, so testing, debugging, and security interest me as much as building. This site collects my education, projects, and résumé in one place.

## What the site contains

- **Education**: degree, school, and expected graduation date.
- **Projects**: cards with a short description, live demo, and repository link (currently [Wolf Peach](https://github.com/hlong200/wolf-peach), a home gardening guidebook).
- **Contact**: email, LinkedIn, GitHub.
- **Résumé**: downloadable PDF.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Single-page site: about, education, projects, contact |
| `style.css` | Styles, with light and dark themes that follow the system setting |
| `Hunter_Long_Resume.pdf` | Current résumé, linked from the nav and hero |
| `photo.jpg` | Portrait shown in the hero section |

The site is plain HTML and CSS with no build step or dependencies. It is responsive, respects reduced-motion settings, and includes a skip link for keyboard users.

## Running locally

Open `index.html` in a browser, or serve the folder with any static server, for example the VS Code Live Server extension.

## Updating

- Edit `index.html` or `style.css` and push to the default branch. GitHub Pages redeploys automatically.
- To update the résumé, replace `Hunter_Long_Resume.pdf` and keep the file name the same so the links keep working.
